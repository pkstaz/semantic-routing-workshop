Puntos clave para explicar

¿Por qué dos interfaces?

  • Dashboard (8700): transparencia — el participante ve el routing
  • Open WebUI (3000): experiencia real — el usuario no ve el routing

¿Por qué tres modelos?

Un solo modelo no es óptimo para todo. El router envía cada query al modelo más adecuado según su significado, no por palabras clave exactas.

Preguntas frecuentes de participantes

¿Puedo usar Docker en vez de Podman? Sí, vllm-sr serve detecta Docker automáticamente. El workshop está escrito para Podman.

¿El router corre en GPU? No. La clasificación semántica corre en CPU local. Los modelos LLM están en OpenShift AI remoto.

¿Puedo agregar más modelos/rutas? Sí, desde el dashboard.

¿Qué pasa si ninguna regla coincide? Se usa el default_model configurado en providers (llama-32-3b).
