6. Levantar Open WebUI

vllm-sr ya debería estar corriendo del paso 5. Si lo cerraste, vuelve a arrancarlo (con el config.yaml que ya creaste):

source .venv/bin/activate
vllm-sr serve

Verifica:

vllm-sr status

Dashboard: http://localhost:8700

PuertoServicio
8899API de chat (Open WebUI apunta aquí)
8080API interna del router (vllm-sr eval)
8700Dashboard web

1. Open WebUI

En otra terminal, desde el mismo directorio donde estás haciendo el lab (donde corre vllm-sr serve).

Descarga docker-compose.yml ahí y levántalo:

curl -fsSL -o docker-compose.yml https://raw.githubusercontent.com/pkstaz/semantic-routing-workshop/devopsdays/docker-compose.yml
docker compose up -d

Abre: http://localhost:3000

La primera vez crea una cuenta local (solo para este entorno).

docker-compose.yml ya apunta al router:

OPENAI_API_BASE_URL=http://host.docker.internal:8899/v1

No eliges modelo en Open WebUI — el router lo hace por ti.

2. Probar rápido

vllm-sr eval --prompt "Write a Python function to sort a list"
vllm-sr chat "What is the capital of France?"

3. Detener (cuando termines el taller)

En el mismo directorio del docker-compose.yml:

docker compose down
vllm-sr stop
