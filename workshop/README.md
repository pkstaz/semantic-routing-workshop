# Semantic Router Workshop

Guías paso a paso para el workshop comunitario.

**Duración estimada:** 90–120 minutos

## Antes de empezar

- Mac Apple Silicon (arm64) o Linux
- Conexión a internet
- Credenciales de OpenShift AI (token + endpoints de los 3 modelos)
